# 🍑 PeachWallet

PeachWallet é um aplicativo moderno de controle financeiro pessoal desenvolvido com foco em praticidade para suprir as minhas expectativas e dores no momento de gerir meus recursos.

O projeto utiliza tecnologias do ecossistema .NET Maui para permitir que usuários registrem gastos, entradas e investimentos, também tendo uma interface amigavel para visualização de relatórios. 

## Tecnologias Utilizadas

- **.NET 9**
- **.NET Maui** 
- **SQLite** (banco de dados local)
---

## Funcionalidades

- Cadastro de **Lançamentos Pontuais e Recorrentes** de diversos tipos, ex: Entrada, Saída, Investimento
- Listagem de **lançamentos por periodo**, com filtros.
- Relatório do **Ano mês a mês**.
- Cadastro de **Saldo Atual** por Conta. 
- Relatório de **Projeção por Ano**, mostrando o saldo a cada ano com as informações atuais do sistema
- **Dedução automática dos Lançamentos** na data onde foram cadastrados.
- **Importação e Exportação** da base de dados local.
